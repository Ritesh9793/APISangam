# APISangam

Backend-first B2B API marketplace project.

## Included

- `backend/` Spring Boot backend
- `files/README.md` detailed backend usage and API docs
- `files/.env.template` environment template
- `files/docs/postman_collection.json` Postman collection

## Quick Start

```bash
cd backend
mvn spring-boot:run
```
